# 2026-10-19

## /projects 页新增天气卡片（复刻 blog.nw177.cn 的 mosaic 天气卡）

- 参考用户提供的站外天气卡元素，在 `/projects` 页创作足迹热力图右侧新增 `WeatherCard`（窄屏 ≤1020px 上下堆叠）。
- 数据链路：`server/weather.ts` 的 Open-Meteo 请求扩展为 current（温度/天气码/湿度/体感/风速风向）+ daily（最高/最低/降水/降水概率/UV/日出日落，`wind_speed_unit=ms`、`forecast_days=1`），防御性解析，核心字段（温度+天气码）不可用时仍返回 `{available:false}`（保持既有测试契约）。
- `shared/weather.ts`（新增）：WMO 代码→中文天气、风向名、蒲福风级、UV 等级、穿衣建议等纯函数，客户端与服务端可共享、可单测。
- `server/visitor-location.ts`（新增）：按访客 IP 定位，提供商链为淘宝 IP（中文）→ ipwho.is（英文备用），成功缓存 6h/失败 10min，内网与保留地址不请求（`isPublicIp`，注意 `::` 未指定地址也要拦截）；app.ts 暴露 `GET /api/visitor-location`，失败回退站点地点。
- 展示逻辑在 `client/src/components/WeatherCard.tsx`：lucide 图标 + 主题 CSS 变量（fresh 用 `var(--theme-*, 回退值)`，blush/midnight 自动适配），实时时钟用 `useClock`（每秒），天气 15 分钟轮询，管理员草稿地点走 `/api/weather/preview`（与 ClockCard 一致的模式）。
- 布局：`.projects-overview` flex 行；热力图基规则去掉 `max-width:50%/margin:auto`、`width` 改 100% 并 `min-width:0`，保证 390px 窄屏不横向溢出（QA 四档宽度通过）。
- 测试：tests/weather.test.ts 增加富字段解析两例；新增 tests/visitor-location.test.ts、tests/weather-details.test.ts。`npm test` 58 过 2 败——api.test.ts 的 EBUSY（Windows 临时文件锁）为基线既有问题，与本次无关（stash 对比验证）；typecheck 通过；browser-qa 四个栏目无溢出等关键项通过（相册查看器 `.photo-meta h3` 超时亦为基线既有 flake）。
